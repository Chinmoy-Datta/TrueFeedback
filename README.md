# 🌟 True Feedback

True Feedback is an **anonymous feedback web application** where users can **receive messages from others securely and privately**.  
Built using **Next.js**, **TypeScript**, **NextAuth**, **ShadCN UI**, and **Tailwind CSS**, this app provides a modern, elegant, and responsive experience.

---

## 🚀 Features

- 🔐 **Authentication** with NextAuth (Sign up, Sign in, and Logout)
- 📨 **Anonymous Message System** — anyone can send feedback messages
- 🗑️ **Message Deletion** with confirmation dialogs
- 🎨 **Beautiful UI** using ShadCN UI and Tailwind CSS
- ⚡ **Real-time Toast Notifications** with Sonner
- 🧠 **Form Validation** with Zod and React Hook Form
- 🌈 **Responsive Design** optimized for all devices
- 🧩 **TypeScript Support** for type safety
- 💾 **MongoDB Database Integration**

---

## 🧠 Tech Stack

| Category | Technology |
|-----------|-------------|
| **Frontend** | Next.js 14, React, TypeScript |

| **Auth** | NextAuth |
| **Validation** | Zod + React Hook Form |
